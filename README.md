# World-Cup-Database
# World Cup Database ⚽  A PostgreSQL database project based on World Cup matches from 2014 and 2018.  ## Technologies  * PostgreSQL * SQL * Bash  ## Files  * `insert_data.sh` — imports teams and games. * `queries.sh` — runs SQL queries and analyzes the data.  This project was completed as part of the freeCodeCamp Relational Database certification.
